Independent appointment booking with a four-step form, availability, staff, customer administration, payments, notifications and reporting.

== Description ==

Intelink Booking is a native WordPress plugin by Intelink Solutions. Use [intelink_booking] in a page to display the booking form. The plugin uses your website logo and configurable business branding. WooCommerce is optional.

See README.md for configuration and TESTING.md for validation instructions. External payment gateway sandbox tests must be completed using your account before deploying online payments.

== Installation ==

1. Upload the plugin ZIP using Plugins > Add New > Upload Plugin.
2. Activate Intelink Booking.
3. Configure timezone, currency, business hours, services and payment methods.
4. Place [intelink_booking] in a WordPress page.

== Frequently Asked Questions ==

= Is WooCommerce required? =
No. Direct payment providers, bank transfer, pay-at-appointment and free bookings operate independently.

= Is data deleted on deactivation? =
No. Booking and payment history is retained. Deactivation clears scheduled maintenance.

= Are live gateway tests included? =
No. Local provider contract tests use controlled HTTP responses. Configure and test real sandbox credentials on your staging website.
